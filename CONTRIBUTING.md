# How to contribute

Everyone is welcome to contribute features, ideas and bugfixes!

# Features
If you are about to contribute a new feature, it would help if first you open an issue to discuss  if and how your contribution fits in to avoid the disappointment of a PR closed due to miscommunication.

__NOTE: Pull Requests submitted without explicit approval received first in an Issue will be immediately closed.__

# Bugs
If you are submitting a bug fix, please attach a minimum reproduction that shows the intended behavior and the bug you're encountering.
